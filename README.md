# 学习打卡与统计助手

这是使用 MoonBit 编写业务逻辑的本地学习记录网页。填写学习内容、分钟数和完成情况后，页面会显示学习统计、历史和本周 Markdown 周报。无需账号；记录保存在当前 Edge 浏览器的本地存储中，不会由本项目的本地网页服务上传。

## 最简单的试用方式

需要电脑安装 Python。在 `04_构建与交付/学习打卡助手_v002` 文件夹打开终端，运行：

```text
python -m http.server 8124 --bind 127.0.0.1
```

保持这个终端窗口打开，然后用桌面版 Microsoft Edge 访问 `http://127.0.0.1:8124/index.html`。停止服务时在终端按 `Ctrl+C`。不要直接双击 HTML 文件：网页使用 JavaScript 模块，需要通过本地 HTTP 地址打开。

关闭网页后，记录通常还在同一个 Edge 配置与同一地址下；清除网站数据、换浏览器或改端口可能导致记录不可见或丢失。**v002 尚无常规的全部记录导出/恢复功能，不要把重要数据只保存在这里。**

## 目前能做什么

- 新增学习记录、查看全部历史、删除错误记录（删除前确认）。
- 查看今日、本周、累计学习分钟、按记录条数计算的完成率、每个主题的投入。
- 生成本周 Markdown 周报，可预览或下载 `.md` 文件。
- 遇到损坏的本地数据时停止写入，并提供下载原始数据的入口，避免静默覆盖。

本周从周一开始；目前不允许填写未来日期。计时器、连续打卡、图表、编辑、CSV、日常事项计划以及普通备份/恢复不属于此 v002 首版。

## 开发与验证

源码位于本目录；`study.mbt`、`storage.mbt`、`report.mbt` 是 MoonBit 业务核心，`web/api.mbt` 导出给浏览器，`public/` 包含网页薄适配层。需要 [MoonBit 官方工具链](https://www.moonbitlang.com/download/) 和 Node.js。完整构建步骤见 `04_构建与交付/构建与运行说明_v001.md`。

目标浏览器是桌面版 Edge。2026-09-18 的临时 Edge 技术验收 8/8 项通过，见 `03_测试与验证/浏览器首版验收_v002.md`；这不等于用户本人已验收。项目仅使用本地 Git，尚未上传 GitHub。
